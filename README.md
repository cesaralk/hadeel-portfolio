# Hadeel Al Souki — Portfolio Website

Static responsive portfolio website prepared for GitHub Pages and Bitreca.

## GitHub Pages
1. Create a repository such as `hadeel-portfolio`.
2. Put `index.html`, `style.css`, and `script.js` in the repository root.
3. Push to `main`.
4. GitHub → Settings → Pages → Deploy from a branch → `main` / root.
5. The URL will be similar to `https://cesaralk.github.io/hadeel-portfolio/`.

## Bitreca
For the existing Vite/React Bitreca project, this static portfolio can be placed under:
`public/portfolio/hadeel/`

Then copy these three files into that folder. After `npm run build`, Vite copies the folder to the deployed site, making it available at:
`https://bitreca.com/portfolio/hadeel/`

If Cloudflare routing redirects that path to the React SPA instead, add an explicit static-asset route or integrate this design as a React page.
